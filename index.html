Older women reached the shortlist less often

What to do next

Ask the person responsible for the system to test it again without career-gap information.

2

Career gaps may make women less likely to be selected

Career-gap information had a strong effect on the model and was different across gender groups. This is a reason to investigate, not proof of discrimination.

What to do next

Explain why the system needs career-gap information, or change how it uses it.

There is enough data for a useful comparison

What to do next

Keep this data so you can compare it with the next test.

What do these results mean?

A marked difference means a person should check the result. It does not by itself prove that the system is unfair or unlawful. FairHire looks at selection results, the number of people in each group, the model's behavior, and possible indirect influences so your team can decide what to do.

Common terms

Fairness check
A check of one system version using one set of data. A teammate can run it again with the same settings.
Action item
A problem that someone needs to investigate, fix, or make a decision about.
Possible indirect influence
Information such as career gaps or postal area that may affect one group more than another.
Group information
Gender, age, nationality, or similar data used only to compare results between groups. The hiring model cannot see it.
